## ttcheckコマンド

バンドの出演リストを標準入力から読み込み、各バンドの開始・終了時刻の自動計算と、メンバーの連続出演（連チャン）の検知を行うコマンドです。

### インストール
```bash
$ git clone https://github.com/nsiro400/robosys2026.git
$ cd robosys2026
```

### 入力形式
`バンド名,持ち時間(分),メンバー(スペース区切り)`

- メンバー欄は省略可能です。
- `#` で始まる行と空行は無視されます。

### 使い方・実行例
引数で開始時刻（`HH:MM`）を指定できます。省略した場合は `00:00` 開始になります。

```bash
$ printf "NEE,15,佐藤 鈴木\nヨルシカ,22,佐藤 高橋\nアニソン,18,伊藤\n" | ./ttcheck 10:00
10:00 - 10:15 (15m) | NEE
10:15 - 10:37 (22m) | ヨルシカ [WARN: 佐藤]
10:37 - 10:55 (18m) | アニソン
Total: 55 min (00:55) | Conflicts: 1
```
